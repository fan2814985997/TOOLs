# 📄 PDF Evidence Miner

A multilingual （中文/English/한국어）desktop tool for automated evidence extraction from large collections of PDF documents.

PDF Evidence Miner is designed for researchers working with policy documents, academic papers, and reports who need to systematically extract keyword-related contextual sentences and export them as structured datasets for further analysis.

---

## 🚀 Key Features

- 🔍 Batch extraction from entire PDF folders  
- 📑 Context-aware sentence capture (not just keyword hits)  
- 🌐 Multilingual support: Chinese, English, Korean  
- ⚙ Flexible matching options:
  - Plain keyword search  
  - Regular expression (regex) mode  
  - English word-boundary control  
  - Automatic deduplication  
- 📊 Structured outputs with metadata:
  - File name  
  - Page number  
  - Matched keyword  
  - Full evidence sentence  

- 📤 One-click export to:
  - TXT  
  - Word (.docx)  
  - Excel (.xlsx)  

- 📈 Real-time progress tracking with status updates  
- 🖥 Fully local execution (no cloud, no data upload)
